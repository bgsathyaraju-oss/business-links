# G. Sathyanarayana Raju — Business Links

A self-contained, mobile-friendly HTML landing page for business links, referral links, and WhatsApp contact.

## Publish with GitHub Pages

1. Create a new repository on GitHub.
2. Upload `index.html` and `README.md` to the repository's root folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site. The URL will appear in the Pages settings.

The profile image is embedded in `index.html`, so no separate image file is required.
